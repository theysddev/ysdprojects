Дизайнеры остаются в Figma

Без выгрузок и плагинов-посредников: Мост читает переменные и компоненты из файла и ничего в нём не меняет.

Три шага от макета до merge

Подключение занимает один вечер. Дальше Мост работает сам и пишет только тогда, когда в Figma что-то поменялось.

  1. 1

    Подключите файл и репозиторий

    Выберите файл Figma с переменными и папку токенов в GitHub или GitLab. Формат вывода — CSS-переменные, Tailwind или JSON.

    Figma Дизайн-системаподключено

    GitHub product/webподключено

  2. 2

    Мост сравнивает значения

    При каждом изменении в Figma сервис сверяет переменные с кодом и собирает список расхождений.

    color/brand#3B5BFF → #3527F5

    radius/md8 → 12

    space/18новый, 72

Вопросы

Не нашли ответ — напишите на [email protected].

Дизайнерам придётся менять процесс?

Нет. Мост читает переменные, режимы и компоненты из файла Figma. Дизайнеры работают как раньше: ничего не экспортируют и не ставят плагины.

В каком формате токены приходят в код?

CSS-переменные, конфиг Tailwind или JSON в формате W3C Design Tokens. Можно включить несколько форматов сразу — все собираются из одного источника.

Мост может сам изменить main?

Нет. Сервис создаёт только отдельную ветку и pull request (в GitLab — merge request). Слить изменения может только человек с правами в репозитории.

Что, если токен в коде уже поменяли руками?

Мост покажет конфликт в diff: значение из Figma, значение из кода и кто менял последним. Решение остаётся за командой.

Что будет после 14 дней Team?

Пространство перейдёт на Free без автоматических списаний. Подключённые файлы и история синхронизаций сохранятся.
