# Временные сайты клиентов

Каждая папка — сайт клиента до переезда на его домен.
Адрес: `https://ysdprojects.space/clients/<папка>/`

Порядок:
1. Новый клиент — папка `clients/<название>/` с `index.html` и файлами.
2. Сайт переехал на домен клиента — удалить папку, адрес перестанет открываться.

Поисковики эти страницы не индексируют (robots.txt закрывает весь ysdprojects.space).
